# Contributing to the UDA Knowledgebase

This repository uses the Unified Documentation Architecture (UDA).

## Choosing the Correct Artifact Type

- Step‑by‑step procedure → Task
- Explanation or theory → Concept
- Static data or configuration → Reference
- Symptom‑driven break/fix → Troubleshooting

See meta/ROUTING.md for details.

## File Naming

- lowercase
- hyphens
- prefix with type

Examples:
- task-install-proxmox-r710.md
- concept-vlan-design.md

## Commit Message Format

task: add proxmox install guide  
concept: expand vlan design  
reference: update r710 dimm map  
fix: correct idrac troubleshooting  

## Template Usage

All artifacts must use the templates in meta/TEMPLATE-GUIDE.md.
