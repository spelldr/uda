# UDA Knowledgebase

This repository implements the Unified Documentation Architecture (UDA) — a structured, doctrine‑driven system for maintaining long‑term technical knowledge.

UDA organizes information into four atomic artifact types:

- Tasks — step‑by‑step procedures
- Concepts — explanations and theory
- References — static facts, inventories, configs
- Troubleshooting — symptom → cause → resolution

See meta/CONTRIBUTING.md for how to contribute.
